### **2. 📐 Mathematics for AI** `(mathematics-for-ai)`
**Primary Focus:** Mathematical foundations of AI/ML algorithms  
**Purpose:** Understand the theoretical underpinnings of machine learning  
**Key Components:**
- Linear Algebra (Vectors, Matrices, Eigenvalues)
- Calculus (Derivatives, Integrals, Optimization)
- Probability & Statistics
- Information Theory (Entropy, KL Divergence)
- Optimization Methods

**Prerequisites:** Basic calculus and algebra  
**Target Level:** Intermediate  
**Expected Outcome:** Ability to derive and understand ML algorithms mathematically

git clone https://github.com/MusaRasa/mathematics-for-AI.git
